## 八、前端页面设计

### 8.1 页面总览与路由

新增 5 个页面 / 组件，共分为 4 个路由：

| 页面 | 路由 | 类型 | 功能 |
|------|------|------|------|
| 检测组管理 | /lims/testGroup | 独立功能页 | 检测组 + 组成员 CRUD |
| 规格书管理 | /lims/specification | 独立功能页 | 规格书 + 检测项目定义 CRUD |
| 报检管理 | /lims/inspection | 独立功能页 | 报检单列表、新增、编辑 |
| 报检单详情 | /lims/inspection/detail/:id | 详情页（二级路由） | 查看报检单+检测项结果 |
| 检测结果录入 | 组件（非页面路由） | 供工作流待办页面嵌入 | 检测员录入结果 |

菜单结构：

`
检测管理 (父菜单，图标: el-icon-s-platform)
├── 检测组管理     → /lims/testGroup
├── 规格书管理     → /lims/specification
└── 报检管理       → /lims/inspection
`

报检单详情和检测结果录入不在左侧菜单出现，通过按钮或任务链接跳转。

### 8.2 API 层设计

前端 API 文件位于 src/api/lims/ 目录，按照后端模块划分：

**src/api/lims/testGroup.js** —— 检测组 + 组成员

`javascript
export function listTestGroup(query)     // GET    /lims/testGroup/list
export function getTestGroup(id)         // GET    /lims/testGroup/{id}
export function addTestGroup(data)       // POST   /lims/testGroup
export function updateTestGroup(data)    // PUT    /lims/testGroup
export function delTestGroup(ids)        // DELETE /lims/testGroup/{ids}

// 成员独立接口
export function listGroupMember(query)   // GET    /lims/testGroupMember/list
export function addGroupMember(data)     // POST   /lims/testGroupMember
export function delGroupMember(ids)      // DELETE /lims/testGroupMember/{ids}
`

**src/api/lims/specification.js** —— 规格书 + 规格书检测项目

`javascript
export function listSpecification(query)     // GET    /lims/specification/list
export function getSpecification(id)         // GET    /lims/specification/{id}
export function addSpecification(data)       // POST   /lims/specification
export function updateSpecification(data)    // PUT    /lims/specification
export function delSpecification(ids)        // DELETE /lims/specification/{ids}

// 规格书项目接口
export function listSpecItem(query)          // GET    /lims/specItem/list?specId=xxx
export function addSpecItem(data)            // POST   /lims/specItem
export function updateSpecItem(data)         // PUT    /lims/specItem
export function delSpecItem(ids)             // DELETE /lims/specItem/{ids}
`

**src/api/lims/inspection.js** —— 报检单 + 检测结果

`javascript
export function listInspection(query)         // GET    /lims/inspection/list
export function getInspection(id)             // GET    /lims/inspection/{id}
export function addInspection(data)           // POST   /lims/inspection
export function updateInspection(data)        // PUT    /lims/inspection
export function delInspection(ids)            // DELETE /lims/inspection/{ids}

export function listTestItem(query)           // GET    /lims/testItem/list?inspectionId=xxx
export function updateTestItem(data)          // PUT    /lims/testItem（更新结果值、状态等）
`

### 8.3 页面布局设计

所有页面统一使用 RuoYi 标准布局：pp-container → 搜索栏 + 操作按钮 + 表格 + 分页 + 弹窗。

#### 8.3.1 检测组管理（	estGroup/index.vue）

`
┌──────────────────────────────────────────────────────────┐
│  [检测组名称] [搜索] [重置]                              │  ← 搜索栏
├──────────────────────────────────────────────────────────┤
│  [+新增] [修改] [删除]                                   │  ← 操作按钮
├──────────────────────────────────────────────────────────┤
│  │ 编码   │ 名称       │ 状态 │ 成员数 │ 操作 │        │  ← 主表格
│  │ PHY    │ 物理检测组 │ 启用 │   3   │ 编辑 │        │
│  ├──────────────────────────────────────────────────────┤  ← 可展开行
│  │ 成员列表：                                           │
│  │ │ 姓名   │ 排序 │ 操作 │                             │
│  │ │ 张三   │  1   │ 删除 │                             │  ← 嵌入子表格
│  │ │ 李四   │  2   │ 删除 │                             │

**交互方式**：展开式布局。点击主表行前的展开图标，下方展开子表格显示该组的成员列表。成员支持在展开行内直接增删。

**新增/编辑弹窗**：el-dialog 内嵌 el-form，包含组名称、编码、状态等字段。

#### 8.3.5 检测结果录入（ssay/input.vue，工作流任务页嵌入）

不是独立菜单页面。通过工作流待办页面点击"办理"时，以 URL 参数方式打开：

`
┌──────────────────────────────────────────────────────────┐
│  检测结果录入 — 报检单 INS20260601                        │
│                                                            │
│  我的检测任务：                                            │
│  ┌──────────────────────────────────────────────────────┐│
│  │ │ 项目  │ 方法  │ 下限  │ 上限  │ 结果输入          ││
│  │ │ 纯度  │ 滴定法│ 98.0  │ 99.5  │ [el-input] → QC  ││  ← 自动判定
│  │ │ 铁含量 │ AAS法 │ 0    │ 0.01  │ 99.2 → P (合格)  ││
│  │ └────────────────────────────────────────────────────┘│
│                                                            │
│  [暂存] [提交]                                            │
└──────────────────────────────────────────────────────────┘
`

- 每个检测项一行，输入结果后前端即时对比规格上下限，显示 QC 结果
- "提交"按钮同时完成：更新 lims_test_item 结果 + 调用工作流 complete 接口

### 8.4 页面间的关联关系

`
检测组管理 ──→ 为规格书检测项目提供"检测组"下拉框数据源
        ↑
规格书管理 ──→ 为新增报检提供"规格书"下拉框 + 检测项目模板
        ↓
报检管理 ──→ 提交报检时从规格书复制检测项到 lims_test_item
    ↓
报检单详情 ←── 查看所有检测项的结果和 QC 判定
    ↓
检测结果录入 ←── 工作流"结果录入"环节打开此页面（带 taskId 参数）
    ↓
工作流待办/已办 ─── 复用项目已有的 workflow/work 页面
`

### 8.5 与工作流任务页面的集成

| 环节 | 跳转方式 | 说明 |
|------|---------|------|
| 待办页面 | 复用 workflow/work/todo.vue | 项目已有的待办列表 |
| 办理跳转 | URL 携带 	askId 和 usinessKey | 跳转到检测结果录入页 |
| 提交后 | 调用工作流 complete API | 关闭页面并刷新待办列表 |
